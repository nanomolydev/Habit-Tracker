# Habit-Tracker
Это REST API для трекинга дневных/недельных привычек

## Возможности
* Создание дневных и недельных привычек
* Возможность задать сколько раз за неделю должна выполниться "недельная задача"
* Возможность просмотреть выполненные за сегодня задачи
* Повторяемость задач с каждым днём

## Стек
Python, Flask, Flask-Smorest, Flask-SQLAlchemy, Flask-JWT-Extended, Marshmallow, SQLite

## Как запустить
Скачать python3.10+

 `git clone https://github.com/nanomolydev/Habit-Tracker`

создаем виртуальное окружение:

Linux/Mac:
```
python3 -m venv .venv
source .venv/bin/activate
```

Windows:
```
python -m venv .venv
.venv\Scripts\activate.bat
```

Устанавливаем зависимости:
```pip install -r requirements.txt```

Создаем .env по примеру .env-example

Запуск:
`flask run`
## Эндпоинты

### Пользователи
| Путь      | Метод | Что делает                                     |
| --------- | ----- | ---------------------------------------------- |
| /register | POST  | Регистрирует пользователя                      |
| /login    | POST  | Входит в аккаунт и отдает jwt токен            |
| /user     | GET   | Выводит имя текущего пользователя и "привычки" |

### Привычки
| Путь               | Метод  | Что делает                     |
| ------------------ | ------ | ------------------------------ |
| /habits            | POST   | Добавляет привычку             |
| /habits            | GET    | Получает привычки              |
| /habits/<habit_id> | GET    | Получает определенную привычку |
| /habits/<habit_id> | PATCH  | Изменяет определенную привычку |
| /habits/<habit_id> | DELETE | Удаляет определенную привычку  |

### Выполнения
| Путь               | Метод | Что делает                    |
| ------------------ | ----- | ----------------------------- |
| /habit-completions | GET   | Список завершенных на сегодня |
